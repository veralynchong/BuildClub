# Remake 第三階段計畫：依 Mercif 設計夥伴回饋調整

- 日期：2026-11-02（AEDT）
- 來源：2026-11-02 與 Mercif（設計夥伴，社群代理商，主攻食品與生活風格）的回饋訪談
- 總原則：先把「研究」做到對方願意天天用，再回頭做拍攝端。對方原話："master one first"，研究是一切的基礎。
- Demo：2026-11-07（六）

## 1. 訪談重點

1. **只看真正爆紅的影片。** 門檻約 100 萬觀看。最好的參考是「粉絲 < 5K、觀看破百萬」；大帳號只要觀看遠超粉絲（例如 100 萬粉絲、2000 萬觀看）也算。觀看很低的影片，倍數再高也沒用。「3.3x」這種寫法外行人看不懂，他們只看粉絲數和觀看數。
2. **每支影片拆成固定欄位。** 他們手動維護的研究表欄位：帳號、平台、關鍵字、粉絲、觀看、連結、影片概念、Hook（前 2 秒）、Scroll stopper、情緒觸發、收藏理由。要分區、用顏色區分，一頁看完。
3. **多支爆紅影片的共同結構。** 貼 5 個連結，回答共同的格式、結構、長度。要依內容類型（街訪、食譜、短劇）分開分析。例子：麵條起源街訪「No、No、No、最後 Yes」。
4. **數字可信度。** 「憑什麼說這是最紅的？手動找會不會更準？」
5. **拍攝端。** 腳本轉 shot list 並附機位建議（他最大的痛點是拍得不夠有創意）。街訪的分鏡其實是問題清單。
6. **企劃看板與核准。** 喜歡 Planning 和等待核准；想要送審通知；被退回的點子能否給別的品牌用。
7. **商業面。** 做競品 USP 比較（4P 加訂價）；目標客群可擴大到醫院、大學等內部行銷團隊；他們的客戶多為食品製造商。
8. **研究 IG 演算法**（留言、互動如何推動影片）。

## 2. 已定的決定（2026-11-02，使用者）

| 問題 | 決定 |
| --- | --- |
| 爆紅門檻 | 做成像 YouTube 的篩選面板，觀看數預設 100 萬+ |
| Hook 類型、情緒觸發 | 固定選項 |
| 研究總表版面 | 由隊友決定，1c 先不做 |
| 測試費用 | 開發和測試用快取或範例資料；使用者會訂閱 Apify，之後再跑 live 搜尋 |

## 3. 階段

### 第 1 階段：demo 前（2026-11-03 到 11-06）

**1a 篩選面板**（分支 `feat/results-filter-panel`）

| 分組 | 選項 | 預設 |
| --- | --- | --- |
| 觀看數 | 不限 / 10 萬+ / 50 萬+ / 100 萬+ / 500 萬+ | 100 萬+ |
| 帳號粉絲數 | 不限 / < 5K / < 5 萬 / < 100 萬 | 不限 |
| 爆紅類型 | 小帳號爆紅（粉絲 < 5K 且觀看 ≥ 100 萬）/ 破圈（觀看 ≥ 粉絲 10 倍） | 不勾 |
| 上傳時間 | 本週 / 本月 / 3 個月內 / 今年 / 不限 | 不限 |
| 長度 | < 15 秒 / 15–60 秒 / > 60 秒 | 不限 |
| 排序 | 觀看 ÷ 粉絲（現行）/ 觀看數 / 最新 | 現行 |

- 已選條件以小標籤顯示在結果上方，每個標籤可按 × 移除。
- 不更動 11/2 定的排序規則（觀看 ÷ 粉絲），只多一層篩選。
- 卡片直接寫粉絲數和觀看數，倍數降為次要資訊。
- Instagram 粉絲數是之後才補進來的：還沒到的影片在套粉絲條件時標「粉絲數載入中」，不濾掉。
- 篩完結果太少時，顯示「放寬到 50 萬+」的提示，不讓畫面空白。
- 只在前端篩選，不改搜尋 API、不加套件。
- 每次搜尋目前只抓 30 支（`RESULTS_PER_SEARCH`）。訂閱 Apify 後再評估調到約 100，並先算好成本請使用者確認。

**1b 拆解欄位**（分支 `feat/breakdown-hook-emotion`）

| 欄位 | 形式 |
| --- | --- |
| 影片概念 | 一句話 |
| Hook 類型 | 固定選項：畫面誘人 / 問題或文字 / 激怒（rage bait）/ 知識型 / 挑戰 / 其他 |
| Scroll stopper | 前 2 秒讓人停下來的原因 |
| 情緒觸發 | 固定選項：好奇 / 興奮 / 嘴饞 / 好笑 / 生氣想留言 / 有共鳴 |
| 收藏理由 | 觀眾為什麼想存起來 |

- 改 `backend/analyze.py` 的 prompt、`backend/models.py` 的 `Why`、拆解面板。
- 舊的拆解沒有新欄位：照常顯示，並提供「重新分析」。
- 同一次 AI 呼叫，不加新的付費服務。

**1c 研究總表**：等隊友決定版面後再做。內容是收藏影片一列一支、欄位照 Mercif 的 Excel、色塊標籤、「複製到 Excel」（TSV）。

**第 1 階段完成條件**
- 搜尋結果預設只顯示觀看 ≥ 100 萬的影片，篩選條件可調、可移除。
- 新的拆解都有上面 5 個欄位；舊拆解不會壞。
- `bash bin/verify.sh` 綠燈；E2E 在 1440 和 390 寬度通過。

### 第 2 階段：demo 後 1–2 週，研究做深

| 項目 | 內容 | 優先度 |
| --- | --- | --- |
| 2a 多支影片共同結構 | 貼最多 5 個連結 → 共同格式、結構、長度、hook 規律（N+1 次 AI 呼叫） | 高 |
| 2b 內容類型 | 關鍵字後選類型（街訪 / 食譜 / 短劇 / 開箱），結果分組並給建議結構 | 高 |
| 2c 數字可查核 | 顯示來源、抓取時間、原始連結、重新抓取 | 中 |
| 2d Mercif 試用一週 | 對方和 Annie 實際使用並回饋 | 必做 |
