Search desk: one box, made smarter

Search stays the main action, as it is today. The page gets better at the two moments around it: a first visit, where the brief writes the first searches, and a return visit, where recent searches show what’s new since last time.

In short
New user

Searches written from the brief

The empty page offers searches that fit Evergreen’s brief, ideas catching on now, and the question, link and screenshot inputs. One click runs a search.

Returning user

Recent searches, with new counts

Their past searches for this client, each re-checked once a day: “6 new since Thu”. Saved videos sit beside them. Filters work on the results as removable chips.

Why this one

Closest to what’s built

  • Keeps the hero, search box, Best to copy and tiles
  • New parts: suggestions as you type, recent searches, new-since counts
  • Risk: still asks the user to think of a search

07. Refine

New first, then filter

Opening a recent search shows the new videos first. The Filters panel uses the app’s current options: platforms, account followers, upload date, viral type. Each choice becomes a removable chip with a live count: “Showing 11 of 24”.

Turning off a platform you already searched is a free filter. Turning on a new one runs a search for just that platform, and the button says so.
