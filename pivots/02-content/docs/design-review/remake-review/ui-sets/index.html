Three ways Remake could look, end to end.

Three full UI directions for the whole product, from the landing page to publishing. All three keep the Remake core: navy and blue, the navy dot grid, Newsreader headings, Inter for reading, Geist Mono for labels. They differ in layout, density, motion, data visualisation and interaction. Every screen uses Evergreen Foods sample content, and the animations and interactions work.

Set A · editorial and calm

Broadsheet

Remake set like a quality newspaper. Each page has one lead story, ledgers instead of card piles, hairline rules instead of boxes, mono datelines and big Newsreader headlines. Navy "night edition" bands carry the dot grid. Motion is slow and quiet: a 550 ms cross-fade with a small rise, lines that rise in order, rules and sparklines that draw themselves, saves that stamp in. It reads well, it is the closest to today's Altitude, and it fits the copy guide's "sentences, not tags".

Set B · studio and tool-dense

Control Room

Remake as a dark production console for the team that lives in it all day. An icon rail, a ⌘K command bar on every screen, panes with an inspector, sortable tables, a followers-vs-views scatter, a real node editor with typed ports, a multi-track timeline and keyboard triage for approvals (A, C, S). Motion is fast and mechanical, 150 to 250 ms: screens slide sideways, data flows along node links, loaders sweep the dot grid. Most power per pixel, but furthest from today's light app.

Set C · bold and kinetic

Signal

Remake as a brand you can feel. The dot grid comes alive: on Best to copy, 267 dots light up, one for each time the video beat its account's usual views. Targets fill as dot rings, columns of dots rise. Giant Newsreader with a mustard highlighter on the key word, top pill navigation, colour-blocked cards, wipe transitions, spring easing, magnetic buttons, tilting covers and a review deck you swipe. The most memorable; the least dense.

My recommendation

Build the product on Broadsheet. Borrow Signal's dot-matrix for the money moments, and Control Room's tools for the make-it screens.

  1. Broadsheet for the everyday screens (Home, Find ideas, Results, Research, Plans, Plan, Review, Brief, Settings). It is calm enough to use all day, it reads at the grade 5 to 7 level the copy guide asks for, and it is the shortest step from today's Altitude tokens: same light canvas, same pills, just better rhythm and rules.
  2. Signal for the landing page and three moments: the dot-matrix "views compared with usual" on Best to copy (it explains the ranking rule without a × score), the target dot ring on Home, and the swipe deck for Review on a phone. Keep the spring motion for those moments only.
  3. Control Room for Canvas and Edit, and its ⌘K command bar everywhere. Node editors and timelines are tool screens; typed ports, a minimap, cost check before "Run the whole shot" and a dark surface are what video people expect there.

Conflicts to decide before building anything. Set C swaps the sidebar for a top pill bar, which changes the navigation in docs/app-flow.md (sidebar with Home, Find ideas, Research, Compare, Plans, Canvas, Channel, Brief). Set B is dark by default, while today the app follows the system theme and opens light. Set B also uses many status pills, which the copy guide asks us to avoid ("use sentences, not tags"). The recommendation above keeps the sidebar and the light default.

Not verified in the live app. Canvas would not load in the running app at :5192 ("Couldn't load the canvas."), so Canvas, Edit and Publish are designed from the strings in lib/strings/canvas.ts, editor.ts and cut.ts and the canvas plans in docs/plans/. All numbers are sample data.
