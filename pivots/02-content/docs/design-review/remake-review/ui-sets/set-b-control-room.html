Control Room: a studio for people who live in it

Remake as a dense, dark production console for the agency team that runs it all day. A command bar on every screen (press the ⌘K box), panes and inspectors, tables you can sort, a real node editor, and fast, mechanical motion. Navy-deep is the base; blue is action, mustard marks the winner.

LayoutIcon rail, command bar, multi-pane workspace with an inspector. Status bar on every screen.
TypeInter at 12 to 13 px for density. Geist Mono for every number. Newsreader only for titles and big figures.
Motion150 to 250 ms. Screens slide 18 px sideways. Data flows along node links; loaders sweep the dot grid.
DataFollowers-vs-views scatter, ratio bars, heat maps, a format donut, hover read-outs.
