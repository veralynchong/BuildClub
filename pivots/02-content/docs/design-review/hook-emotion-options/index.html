How a hook shows the emotion it creates

Daphne asked that each suggested hook show what the viewer feels in the first ~2 seconds. The emotion is fixed: a label, not a control. Five ways to show it on the current hook card. Everything else on the card is copied from the app (storyboard.css, drawer-plan.css, theme-remake.css).

Recommendation

Go with E, the first-2-seconds line

  • It cannot be mistaken for a control. Remake uses pills for buttons; every chip option (A, B, C) puts a filled shape a few pixels from the pill “Use this”. E has no container at all: mono caption, then plain text.
  • It answers the actual question. The 0:00–0:02 caption names the window Daphne asked about, and matches the timecodes in the Shot list below.
  • The why is what makes the label useful. “Curiosity” alone is a guess; “Curiosity · asks a question only the video can answer” is something the team can say to Evergreen Foods.
  • Accessible by construction. Word always present, ink on white (17:1) and muted on white (6.3:1), screen readers hear “Viewer feels: Curiosity”.

If the extra card height is a problem, fall back to B with the square tag. Avoid C: blue tints collide with the blue main action.

Emotion picks for the samples

  1. Curiosity · “Did you know tofu hacks could look like this?”
  2. Relief (not Anticipation) · “Watch this: tofu hacks, start to finish”. Anticipation is not in the planned list and would overlap with Curiosity. The pull here is the fix for “No tofu press?”, which is Relief.
  3. FOMO / insider · “3 things nobody tells you about tofu hacks”

Flags for the build

  • Today's locked state is one line, not three cards (hook-yours in PlanHooks.tsx). The locked cards below follow this brief; if the one-liner stays, add the same line under it:

Shot 1 starts with: "Did you know tofu hacks could look like this?"0:00–0:02 · Viewer feelsCuriosity · Asks a question only the video can answer.

  • The breakdown drawer already has an emotion chip (.tag-emotion, violet pill) with a different list (curious, excited, craving, funny, angry_comment, relatable in types.ts). Settle one list before building.
  • Light theme only here; dark tokens exist in theme-remake.css and E uses only ink/muted, so it carries over.
