把爆款變成分鏡的位置,還沒有人佔

結論先講:跟 Trend Finder 相鄰的產品大約有 22 個,分成四層,但沒有一家把「找到自然流量的爆款 → 歸納格式 → 給真人拍的可編輯分鏡 → 客戶批准」串起來。YC 名單和 GitHub 也是同一個空白。

先看結論

找趨勢的工具(Sandcastles、Virlo、Format Finder)做到腳本就停了。「複製這支廣告」的生成器(Creatify、MakeUGC、Higgsfield)拿的參考素材是 Meta 廣告庫,產出的是 AI 演員影片,不是給剪輯師的分鏡。剪輯和切片工具(OpusClip、Submagic、Captions)只處理你已經有的素材。

YC 名單也一樣:投資集中在生成、AI 剪輯和「代理商即軟體」,負責「找」的那一層只剩 Bluma(F25,複製對手爆紅影片,但做的是生成)和 Syncly(W23,給大型 CPG 品牌的影片社群聆聽),唯一純做趨勢分析的 Trendpop(W21)在 2022 年被收購。

GitHub 上能直接放進商業產品的,只有底層工具:yt-dlp、PySceneDetect、faster-whisper／WhisperX。功能最接近的 ViralMint 是 AGPL 授權,只能參考不能抄。

2026-10-30 我們用 Apify 實際抓了 8 個品牌的 TikTok 和 7 個品牌的 Instagram(花費 US$0.67)。這些品牌點閱最高的影片,大多不是自家的產品 demo,而是創作者合作貼文、付費推廣,或 CapCut 那種「範本」機制。Instagram 播放前 10 名的 reel 全部用「留言 X 拿連結」當 CTA;TikTok 上標為廣告的影片,按讚率中位數只有 0.65%,自然流量的影片是 6.46%。

這次也順便解開了上一輪的懸念:clockworks 的 profileSorting: popular 是照按讚數排序,不是照播放數(8 個帳號 8 個都是)。所以之後的搜尋要多抓一些再自己用播放數重排,並且把廣告和合作貼文標出來,不然「爆款」會混進買來的流量。

兩個口徑提醒。Instagram 的數字只是「最近 12 支 reel 裡最高的」,不是帳號的歷史最高。TikTok 的 popular 是照按讚數排序,不是照播放數,所以播放高但讚少的影片(例如付費推廣)可能根本沒被抓進來。

結論一:最接近我們的是 Format Finder(概念)和 Virlo(客群),但兩者都沒有「客戶批准」,也沒有把某支真實爆款轉成分鏡。

證據

Format Finder 是唯一寫明會產出「shot plans」的產品,但它的格式是人工整理的 65 個固定格式,不是從你的利基即時抓出來的,也不追蹤頻道 (Format Finder) 廠商自述。Virlo 明說要服務「管理多個客戶帳號的代理商」,但產品做到腳本為止,自家部落格還建議行銷人把輸出丟進 AI 影片工具 (Virlo) 已核對原頁。所有產品的公開定價頁,都找不到給客戶簽核分鏡的流程;「審閱」指的是分享連結(Opus、Submagic),或是代管服務裡的一個步驟(Icon 付款前讓你看 6 份腳本) (Opus、Icon) 已核對原頁。

推理

推論 Trend Finder 的差異不在「找得到 outlier」(這已經是商品),而在兩個步驟:一是把「一支真實的爆款」抽象成「一個格式」,再轉成「這個客戶能拍的分鏡」;二是讓客戶在拍攝前簽核。這跟上一份報告的結論一致:缺的是代理商流程,不是 AI 能力。

弱點

判斷只根據公開定價頁和功能頁,登入後的功能都沒有實測。Format Finder 的資料出自它自己寫的比較頁。

結論二:「複製爆款」這件事,市場的主流答案是不拍了、改用 AI 演員;Icon 反向轉回真人,是唯一一個支持「真人拍攝」的訊號。

證據

資金流向很一面倒:Higgsfield 估值 $5.4B、HeyGen ARR 超過 $200M、Mirage 募 $75M、Creatify A 輪 $15.5M;Sandcastles、Blort、Format Finder 都找不到融資紀錄 (TNW、HeyGen、BusinessWire)。Icon 原本是「The AI Admaker」,2026 年改賣每月 $1,000 的真人 UGC,主打「no AI / 100% real」 (Icon) 已核對原頁 廠商自述。另外,這幾家生成器「複製」的參考來源多半是 Meta 廣告庫,不是 TikTok／Reels 的自然流量(Creatify、Virlo Pro、Icon)。

推理

推論 Mercif 的剪輯師在印尼、拍的是真人,賣的是真實素材和手藝。生成器越便宜,「為什麼還要真人拍」的壓力越大,所以我們的說法要站在「品牌安全＋客戶信任」上,而不是「比較省」。法律上也比較乾淨:把來源影片只存成連結、產出新的分鏡給真人拍,比 Higgsfield Recreate 這種直接複製動作和肖像的做法風險低(這是一般原則,未經律師確認)。

弱點

Icon 的轉向只是一個案例,「AI UGC is illegal as of June 9, 2026」那句話在它頁面上沒有出處,我們無法確認。

結論三:關於剪輯層,上一份報告已經確認它是商品,這次的新資訊只有一個:Munch 已經從切片工具變成「腳本＋生成」套件,並在定價頁放了「For Agencies」。

證據

Munch 的 Premium 方案是 $60／月,包含無限腳本、30 支生成影片、無限團隊成員,頁面上沒有它過去宣傳的爆紅分析 (Munch) 已核對原頁。

推理

推論 剪輯工具正往上游的「腳本」移動,這是值得盯的威脅方向,但目前還沒有任何一家往「分鏡簽核」移動。

弱點

Munch 的頁面沒有說明代理商功能具體是什麼。

結論四:YC 裡沒有一家做「小代理商＋分鏡＋客戶批准」;最該盯的是 Bluma,最該小心的是 Knowlify 這類「代理商即軟體」。

證據

Bluma 的 YC 頁寫的是「自動化消費品行銷,端到端複製對手的爆紅影片」,自家網站只提到「source video reference → new variants」,沒有定價或客戶 (YC: Bluma、getbluma.com) 已核對原頁。Knowlify、Tell if AI、InstaAgent 賣的都是成果,不是工具:Knowlify「價格寫在提案裡」,Tell if AI 收營收分成 (YC: Knowlify、YC: Tell if AI) 已核對原頁。Syncly 的 ARR $2.1M、Trendpop 被收購、Kuli 鎖定 Fortune 100,都在大品牌端 (YC: Syncly、YC: Trendpop、YC: Kuli)。

推理

推論 YC 的空白處跟商業市場的空白處是同一塊,等於兩邊互相印證「找＋分鏡＋批准」沒人做。但「代理商即軟體」的公司如果做起來,Mercif 這種小代理商的客戶會被搶走,這比任何工具競品都更直接。

弱點

YC 名錄是延遲載入的,研究員在 video(72 家)、marketing(140 家)、content(79 家)三個分類只看到前 50 筆,排序是新批次在前,2021 年以前的公司可能漏掉。所有公司的 TikTok／IG 帳號都沒找到(YC 頁只列 X 和 LinkedIn),所以這次的 Apify 實測沒有涵蓋任何 YC 公司。Creatify、Affogato 是不是 YC 公司都無法確認。

結論五:這一層唯一的退場和失敗案例,都指向同一個教訓:純做生成的薄包裝會被模型吃掉,純做趨勢分析則賣不大。

證據

Reforged Labs 在 2026-08 收掉,執行長說「市場很小」、「模型強到我們重寫了產品的大部分」、「我們賣的那個缺口正在關閉」;它的種子輪是 2024 年的 $3.9M (PocketGamer.biz) 已核對原頁。Trendpop 很早就獲利,然後在 2022 年賣給 Collab,原因沒公開 (YC: Trendpop)。YC 目前的 Requests for Startups 列了 11 項,沒有一項跟影片、內容或創作者有關 (YC RFS) 已核對原頁。

推理

推論 Trend Finder 如果只是趨勢清單,會走 Trendpop 的路;如果押在生成,會走 Reforged 的路。押在「流程＋決策紀錄」比較不受模型進步影響,這跟上一份報告的護城河結論一致。

弱點

每個方向都只有一個案例,不能當成規律。

證據

上表 stars、commit 日期、授權,都是研究員 2026-10-30 用 GitHub API 讀的 已核對原頁。ViralMint 的 README 寫了 outlier 是頻道基準的 3x–20x、Scout／Analyzer／Generator 幾個 agent,以及 MCP server,但沒提到把影片歸成格式 (ViralMint)。研究員用 GitHub 搜尋和 topic 查詢,找不到任何做短影音格式分群的 repo。

推理

推論 以我們的技術棧(Node／React＋Apify),實際能重用的是「當成子程序或服務呼叫」的 Python 工具(PySceneDetect、Whisper 系列),以及 MIT／Apache 授權 repo 裡的 prompt 和 schema,而不是把函式庫 import 進 Node app。PySceneDetect 的鏡頭邊界加上 WhisperX 的逐字時間戳,就是一份分鏡的骨架:第幾秒換鏡、這一鏡講了什麼。剩下的「這一鏡要拍什麼」再交給多模態模型。格式分群沒人做,正好也是我們的差異。

弱點

沒有任何 repo 實際跑過,功能描述都是 README 的說法。GitHub 搜尋對多字詞查詢的結果偏少,命名不尋常的 repo 可能漏掉。AGPL／GPL 的 repo(ViralMint、MoneyPrinterV2、Postiz、TikTokDownloader)不能把程式碼抄進閉源產品。

結論七:非官方的 TikTok／IG 爬蟲天生就脆弱,正式產品繼續外包給 Apify 是對的。

證據

TikTok-Api(6,720 星)的 README 自己寫,EmptyResponseException 代表「TikTok 在擋你、偵測到你是機器人」(TikTok-Api);5,238 星的 drawrowfly/tiktok-scraper 從 2023-04 後就沒更新 (repo);instagrapi 的 README 建議正式環境改用付費的 HikerAPI (instagrapi);TikTok 服務條款(2025-12-01 版)禁止「用自動化腳本收集資訊」(TikTok ToS) 已核對原頁。

推理

推論 外包給 Apify,把「壞掉要修」的成本轉給別人,但沒有消除服務條款的風險。比較安全的做法是:只用登出狀態的公開資料、不下載影片(shouldDownloadVideos: false)、只存指標和連結、顯示時連回原貼文。

弱點

沒查澳洲法律;Meta v. Bright Data 的判決只涵蓋登出狀態的爬取,而且只有搜尋摘要 (Quinn Emanuel)。

這些品牌最紅的影片,大多不是自己拍的產品 demo

各品牌點閱最高的影片

用 Trend Finder 自己的公式(最高播放 ÷ 帳號中位數)看 IG 最近 12 支:Higgsfield 23.8 倍(中位數 108,399)、MakeUGC 250 倍(中位數 3,966,最高那支是合作貼文)、Submagic 10.9 倍、Creatify 4.0 倍、Munch 2.7 倍、HeyGen 和 Captions 都只有 1.7 倍 Apify 實測。也就是說,以這兩週到兩個月的窗口來看,HeyGen 和 Captions 的 IG 很穩定,沒有真正的爆款;MakeUGC 和 Submagic 的「爆款」都不是它們自己發的。

這些爆款的共同模式

結論八:在 Instagram,紅的是「創作者合作＋留言關鍵字拿連結」,品牌自己的帳號很小。

證據

Apify 實測 IG 播放前 10 名的 reel,10 支的文案都有「Comment／Comenta X」。全部 84 支裡,有這種 CTA 的 32 支播放中位數是 20,018,沒有的 52 支是 2,613。創作者合作貼文(發文者不是品牌本身、品牌掛共同作者)有 16 支,播放中位數 20,018;品牌自己發的 68 支,中位數只有 3,299。Submagic 最近 12 支 reel 全部是創作者發的;MakeUGC 播放最高的 3 支也都是合作貼文。16 支合作貼文裡,有 5 支帶有 Instagram 的 paidPartnership 標記(@russestudiosv、@mr.k.videography 兩支、@jennasharp.edits、@likfoon)。

推理

推論 「留言關鍵字 → 私訊連結」同時做兩件事:把留言數灌高(演算法訊號),又把觀眾導進 DM 漏斗。這些 AI 工具品牌的成長方式,比較像聯盟行銷或付費創作者計畫,而不是品牌帳號的內容。對 Trend Finder 有兩個直接含意。第一,如果客戶的利基裡有很多合作貼文,「爆款」可能反映的是那位創作者的粉絲盤,不是格式本身,所以資料要標出 ownerUsername 跟抓取帳號不同的貼文。第二,「留言 X 拿連結」本身就是一個可以寫進分鏡的格式元素。

弱點

CTA 的效果跟品牌混在一起。Higgsfield 12 支全部有 CTA,而且帳號本來就大;在同一個品牌內部比較(Captions:有 CTA 的 8 支中位數 17,372,沒有的 4 支 16,070),差距幾乎消失。所以比較可能的解釋是「合作創作者的觸及」,CTA 只是附帶的特徵。樣本只有 7 個品牌、84 支,而且都是 AI 工具這個利基。另外,研究筆記把 @dreomar 歸給 Captions,但原始資料顯示它是從 submagic.co 抓到的,共同作者也是 submagic.co,本報告採用原始資料。

結論九:在 TikTok,不少「最高播放」其實是付費推廣;按讚率是最簡單的分辨方法。

證據

Apify 實測 8 個有回傳資料的 TikTok 帳號、96 支影片裡,有 13 支的 isAd 是 true,包括 Captions 第一、二名(303,300、284,500)、HeyGen 第一、二名(429,300、98,200)、Submagic 第二、三名(343,000、283,500)。這 13 支的按讚率(讚 ÷ 播放)中位數是 0.65%,其餘 83 支是 6.46%,差了約 10 倍(見 Fig. 1)。例如 HeyGen 的聖誕老人影片有 42.9 萬播放,卻只有 938 個讚。

推理

推論 付費推廣把播放數撐高,但觀眾不太互動。如果 Trend Finder 把這種影片當爆款推薦給客戶,等於叫客戶去翻拍一支「花錢買來的觀看」。所以排序前要先排除 isAd,就算沒有這個欄位,也要把「播放高但按讚率低於某個門檻」的影片標成「可能是付費」。上一份報告提到 IG 的觀看數也混了付費流量,這次在 TikTok 看到的是同一個問題。

弱點

clockworks 的頁面沒有定義 isAd 的意思,「等於付費推廣」是我們從按讚率差異推出來的。Instagram 的 reel-scraper 只有 paidPartnership(合作標記),沒有廣告標記,IG 的付費流量還是分不出來。

結論十:小品牌最好的自然流量是跟產品無關的職場幽默,大品牌最好的是「看完就能照做」的範本。

證據

Apify 實測 Munch 的 TikTok 第一名(56,200)和 Creatify 的第一名(16,800)都是辦公室幽默短劇,分享數(730、419)在各自帳號裡最高,遠高於它們的產品示範。CapCut 前三名合計 1.59 億播放,都是範本或教學,收藏數 24.5 萬到 41 萬。Virlo 最好的一支(16,400)是自己翻拍一個熱門梗,文案再說「這個趨勢是用 Virlo 找到的」。Submagic 最好的一支(561,000、按讚率 8.8%)用的是反向 hook「別用這些工具」。

推理

推論 這對 Mercif 的客戶(食物和生活風格品牌)有參考價值:「可以照做」(收藏)和「想傳給某個人」(分享)是兩種不同的爆紅動機,格式卡片上應該分開標,而且分享和收藏正是上一份報告說「拿不到別人的」指標。TikTok 透過 Apify 其實拿得到 shareCount 和 collectCount,Instagram 拿不到。Virlo 的做法(把產品示範藏在翻拍裡)也正好就是 Trend Finder 要幫客戶做的事。

弱點

每個品牌只有 12 支,而且 TikTok 的「popular」是照讚數挑的(見結論十一),播放高但讚少的影片可能根本沒被抓進來。CapCut 的數據大多是 2021–2022 年的,那時的 TikTok 演算法跟現在不同。

之後怎麼搜:先修正排序,再分利基跑

結論十一:clockworks 的 profileSorting: popular 是照按讚數排序。要找「播放最高」,至少抓 30–50 支再自己重排。

證據

Apify 實測 8 個帳號回傳的 12 支影片,8 個都完全照 diggCount 由大到小排,沒有一個照 playCount 排。例如 CapCut 的回傳順序是 5,090 萬、2,340 萬、1,350 萬、8,480 萬播放,對應的讚是 290 萬、220 萬、210 萬、180 萬。上一輪研究只能從第三方頁面推測「Popular (most liked)」(scrapelabsapi) 僅摘要,clockworks 自己的頁面只寫「most popular videos first」(clockworks),這次實測確認了。同一個 actor 頁面也寫了,TikTok 把 popular 排序限制在每個帳號大約 400–500 支 (clockworks/tiktok-scraper) 已核對原頁。

推理

推論 付費推廣的影片讚少,所以在「照讚數排」的前 12 名裡反而會被擠下去,但它們的播放可能更高(Captions 的廣告片就是這樣,排在第 3、4 位)。如果只抓 12 支,看到的是「最多人按讚的」,不是「最多人看的」。抓 30–50 支,再用 playCount 重排、排除 isAd,才是我們要的榜單。

弱點

只測了 8 個帳號、每個 12 支,沒測更深的位置是否也照讚數排。

結論十二:TikTok 的有效單價是標價的兩倍以上,預算要用實測數字算。

證據

Apify 實測 TikTok 這一輪 120 筆(96 筆帳號＋24 筆搜尋)花了約 US$0.45,等於每 1,000 筆約 US$3.75,是 clockworks 標價「from $1.70 / 1,000」的兩倍多 (clockworks)。IG 84 筆約 US$0.22,等於每 1,000 筆約 US$2.6,跟 reel-scraper README 寫的免費方案價 $2.60 一致 (instagram-reel-scraper) 已核對原頁。

推理

推論 TikTok 多出來的部分,可能是免費方案的費率比較高,或是 /video 搜尋分頁、啟動事件另外計費。實際原因要到 Apify 的 run 明細裡看。在搞清楚之前,用 $3.75／1,000 來估預算比較保險。Apify 免費方案每月有 US$5 額度 僅摘要 (Apify pricing),以實測單價計算,大約是 1,300 筆 TikTok,或 1,900 筆 IG。

弱點

費用是從 Apify 月用量 API 讀出來的,可能有延遲;只有一次 run,樣本很小。

搜尋手冊

以下的設定和成本,是根據上面的實測和 actor 頁面整理的;關鍵字清單是本報告的建議,還沒驗證過 推論。

關鍵字策略 推論

這次實測最重要的教訓是:泛用詞會抓到「AI 做的內容」,不是「關於 AI 工具的內容」(ai video editing 的前三名都是 AI 生成影片或範本教學)。所以要分三類來搜。

第一類:品牌名(不分語言,適合跨區域)Opus Clip、Submagic、HeyGen、Higgsfield、Creatify、MakeUGC、CapCut template、Captions app
第二類:「教學／意圖」詞capcut template tutorial、how to make ai ugc、ai ugc ads、ai avatar video、long video to shorts、recreate viral video、steal this video idea、remake any video
第三類:這次看到的 CTA 句型(直接撈出合作創作者的貼文)comment for the link、comment UGC、comment captions

單字 hashtag(#aiugc、#ugcads、#capcuttutorial、#aivideoeditor、#opusclip、#heygen)留給 hashtag 爬蟲;多字詞一律用關鍵字搜尋,因為 IG hashtag 爬蟲會把多個字合成一個 tag,結果變少 (instagram-hashtag-scraper),TikTok 每個 hashtag 也只能拿到大約 400–800 支 (tiktok-hashtag-scraper) 已核對原頁。

區域方面,Mercif 在澳洲,要設 proxyCountryCode: "AU"(clockworks)或 location: "AU"(apidojo);這兩個欄位確實存在,但沒有來源測過它們對結果影響多大。中文的 AI 剪輯、AI 翻拍 內容大多在抖音,TikTok 爬蟲抓不到。

給客戶利基用的版本 推論

上面這套是用來監看競品的;換到 Mercif 的食物和生活風格客戶,流程一樣,只是把關鍵字換成利基詞(例如菜系、城市、「Sydney cafe」這類),先跑 B1／B3 找出陌生的小帳號爆款(這就是 Mercif 的「1-to-10」研究法),再對找到的帳號跑 A2,用中位數確認是不是真的 outlier。每週預算抓 10 個關鍵字(約 US$1.1＋US$1.6)加 10 個帳號(約 US$1.1＋US$1.3),一週約 US$5,剛好是免費方案一個月的額度,所以正式跑之前要先升級方案,或是降低頻率。

弱點:所有成本都建立在一次、約 200 筆的實測上。apidojo 和 instagram-search-scraper 這次都沒有跑。關鍵字清單沒有經過任何量測,下一步應該每個詞先抓 10 筆試水溫。

總結

這次研究改變最大的,是我們對「爆款」這個詞本身的信任。看完 AI 工具品牌自己的數據,排在最前面的常常是付費推廣(TikTok 上按讚率低了 10 倍)、別人帳號的合作貼文(Submagic 最近 12 支 IG 全是),或是照讚數而不是播放數挑出來的結果。只要 Trend Finder 排序前不先過濾這三種偏差,就會把「花錢買的觀看」和「借來的粉絲」當成「可以翻拍的格式」推薦給客戶。

所以下一步要補進產品的不是更多數據來源,而是三個標記:isAd／低按讚率、合作貼文、以及「最近 N 支」的口徑說明。這三個標記成本都很低,也正好延續上一份報告「把計算攤開」的方向。

第二個收穫是位置。從商業產品、YC 名單到 GitHub,大家要嘛在做「找」(而且賣不貴),要嘛在做「生成」(而且越做越不需要真人),中間「把一支真實爆款轉成某個客戶能拍、而且客戶簽過名的分鏡」這一段,三個地方都是空的。空著有兩種解釋:機會,或是市場太小。Reforged Labs 和 Trendpop 的下場提醒我們,答案不在研究裡,而在 Mercif 願不願意每週真的在這一段做決定。
