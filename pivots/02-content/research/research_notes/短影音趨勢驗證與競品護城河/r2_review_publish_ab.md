# Post-production workflow infrastructure for an agency short-form video tool (review, publishing APIs, native A/B, analytics)

Date accessed for all sources: 2026-10-30. Free web search/fetch only; nothing was signed up for or paid. Many pricing numbers come from competitor/vendor marketing pages or aggregators; these are flagged "vendor-biased" or "unverified". Where WebFetch of an official page returned a summary rather than raw text, I say so only where it matters.

## 1. Timestamped review: Frame.io (features, pricing, API) and alternatives, incl. build-your-own

### Takeaway
Frame.io is the reference product, but it is priced per member (Pro $15, Team $25), and its V4 API now needs Adobe OAuth and still lacks several review features (annotations, comment status/completion, reactions are missing or undocumented). Several cheaper or flat-priced alternatives (Krock.io, Vimeo Review, Dropbox Replay, Wipster) have time-coded comments. For a short-form (vertical, 15-60s) agency use case, a custom build is technically small (a video player plus comment-at-time storage) but frame-accuracy, annotations and guest-review links are the real work.

### Cited Findings
**Frame.io pricing and features**
- Frame.io pricing page (fetched 2026-10-30): Free $0 (up to 2 members, 2 GB, up to 2 projects); Pro $15 per member per month (up to 5 members, 2 TB + 2 TB per extra member); Team $25 per member per month (up to 15 members, 3 TB + 2 TB per extra member); Enterprise custom. Annual billing saves 13%. External clients can view and comment on share links without an account (per FAQ). The flattened page text did not show which plan includes frame-accurate/range comments, version stacks or approvals, so plan-level feature mapping is NOT verified. — [Frame.io Pricing](https://frame.io/pricing)
- Third-party price trackers disagree (Pro $13 vs $15; Team $22 vs $25), so some are stale; the official page figures ($15/$25) match Recurdash and Krock's (vendor-biased) quote "as of September 2026". — [Capterra/search summary](https://www.capterra.com/p/148214/Frame-io/pricing/); [Recurdash](https://recurdash.com/subscription-pricing/frame-io); [Krock.io Frame.io pricing page](https://krock.io/frame-io-pricing/)
- Frame.io's pricing page lists frame-accurate and range-based comments, version stacks, "Review & Approvals", and internal comments (Team plan, to separate internal from client conversation). — [Frame.io Pricing](https://frame.io/pricing)
- Third-party reviews describe reviewers pinning comments/drawings to exact frames, uploads grouped into version stacks, comments tied to a specific version, and approval as a review-stage step. These are secondhand (directory/review sites). — [Beverly Boy](https://beverlyboy.com/filmmaking/what-is-frame-io/); [The Digital Project Manager](https://thedigitalprojectmanager.com/es/tools/resena-frame-io/)

**Frame.io V4 API (official migration guide, fetched 2026-10-30)**
- Comments: create via POST `/v4/accounts/{account_id}/files/{file_id}/comments` with body like `{"text":"Nice","timestamp":12.3}`; list on a file at `/files/{file_id}/comments`; show/update/delete at `/v4/accounts/{account_id}/comments/{comment_id}`. The guide says `timestamp` is a framestamp (starting from 1), not seconds. — [Frame.io Legacy API to V4 Migration Guide](https://developer.frame.io/platform/docs/resources/migration)
- Not yet in V4 per the same guide: comment reactions (emojis), viewing or changing comment completion status, comment impressions. Annotations are not covered in the guide; a forum reply (unofficial) says annotations are not yet supported via the API. — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration); [Frame.io forum, V4 early access thread](https://forum.frame.io/t/introducing-the-frame-io-v4-api-early-access-program/2407?page=2)
- Versions: V4 splits "assets" into files, folders and version stacks. Create a version stack with POST `.../folders/{folder_id}/version_stacks` (2 to 10 file IDs); unversioning is not supported. — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration)
- Sharing: review links and presentations are merged into "shares" (e.g. `"type":"review"`), manageable via API; legacy review links cannot be managed via V4. — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration)
- Status/labels: guide does not cover labels or approval status; the only status endpoint reported is for remote-upload status. Approval state via API is therefore unverified. — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration)
- Auth: V4 uses OAuth 2.0 through Adobe Developer Console (user auth or server-to-server); legacy developer tokens still work only on auto-migrated accounts not under Adobe Admin Console (header `x-frameio-legacy-token-auth: true`). — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration)
- Webhooks: migrated V3 webhooks are disabled on migration; V4 create is POST `/v4/accounts/{account_id}/workspaces/{workspace_id}/webhooks`; signed with HMAC SHA256 (`X-Frameio-Signature`, `X-Frameio-Request-Timestamp`). — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration); [Frame.io V4 Webhooks](https://developer.frame.io/platform/docs/guides/webhooks)
- Rate limits: not published in the guide (only 429/500 retry guidance). V2 end-of-life date: not found. — [Migration Guide](https://developer.frame.io/platform/docs/resources/migration)
- Forum report (unofficial): a comment left at ~12 seconds came back as 293.0, i.e. frames, so the client must convert using the asset frame rate. — search summary of [Migration Guide](https://next.developer.frame.io/platform/docs/resources/migration) and [forum](https://forum.frame.io/t/introducing-the-frame-io-v4-api-early-access-program/2407?page=2)

The page did not mention timestamped comments or API, so those features are not confirmed from this source. — [Krock.io](https://krock.io/frame-io-pricing/)

Other listings show different, probably stale numbers. Timestamped-comment feature not verified in this pass. — [ReviewStudio pricing](https://reviewstudio.com/pricing-plans/); [Capterra](https://www.capterra.com/p/146845/ReviewStudio/pricing/)

### Inferences
- Cost per seat matters: the outsourced editors (Indonesia), manager, and client are many people per agency. Frame.io seats cost $15 to $25 per member, but reviewers via share links appear free; flat-fee or unlimited-reviewer tools (Krock.io claims unlimited reviewers on all plans) may be cheaper at agency scale. Whether editors count as "members" is not stated.
- The Frame.io V4 API gaps (comment status, annotations, reactions) mean a thin integration would lose resolved/open state, which is core to a revision workflow.
- For short-form (<=60s, vertical) review, a minimal in-house version (HTML5 `<video>`, store `{asset_version_id, frame_or_seconds, text, status}`, signed guest links) seems feasible; frame-accurate seeking depends on known fps (the HTML5 element exposes seconds; `requestVideoFrameCallback` exists in browsers but I did not verify it from a source here, so treat as unverified). Annotations (drawing on a frame) are the costlier piece.
- Frame.io is a high-leverage "buy" only if clients already use it; embedding it in our product is constrained by Adobe OAuth and per-member plans.

### Gaps

- Official pricing and feature pages for Wipster, Ziflow, Filestage, Dropbox Replay, ReviewStudio (feature side), and API availability of any alternative: not verified.
- Licenses and maintenance status of the open-source libraries; frame-accuracy of any of them: not verified.

## 2. Social publishing APIs (Ayrshare and alternatives; platform requirements and limits)

### Takeaway
Ayrshare is the established multi-profile option for agencies: Launch $299/mo (up to 10 profiles) and Business from $599/mo (30 profiles, tiered beyond) per its pricing page, with Instagram Reels, TikTok, YouTube Shorts and Instagram Trial Reels all supported. Cheaper per-account challengers exist (Zernio/Late, Upload-Post), but their pricing claims mostly come from competitors. Platform-side gating (Meta App Review for Advanced Access, TikTok audit, YouTube audit/quota) is the real onboarding cost if going direct.

### Cited Findings
**Ayrshare**

Add-ons: Max Pack $300/mo; Facebook Boosted Ads $100/mo. FAQ says every plan includes unlimited API calls and posts; per-profile rate drops "from $7.99 to $1.99" on annual billing beyond 500 profiles; Business plans require a minimum of 10 or 30 profiles. The per-tier rates (31-100, 101-500) are not listed. — [Ayrshare Pricing](https://www.ayrshare.com/pricing.md)
- Launch is capped at 10 user profiles with the same post quotas and API limits as Business; the 11th profile requires Business. — [Ayrshare: Business/Launch overview](https://www.ayrshare.com/docs/multiple-users/business-launch-overview)
- A competitor comparison (Upload-Post, vendor-biased, "prices verified 29 September 2026") reports Ayrshare Premium 1 profile / up to 14 accounts, Launch 10 profiles / 140 accounts, Business 30 profiles / up to 420 accounts, 17% annual discount. - Ayrshare's own 50 IG posts/day vs Meta's 100/day is a discrepancy, but neither matters for small agency volume.

## 3. Native A/B testing: YouTube, Instagram, TikTok, Facebook, and API access

### Takeaway
No platform offers a native, API-controllable A/B test of two versions of the same organic short video. YouTube Test & Compare explicitly excludes Shorts and is Studio-only. Instagram Trial Reels is the closest organic mechanism, and the Content Publishing API can now create Trial Reels, but graduation is manual and no trial-specific metrics or follower split were found in the API. TikTok split testing is a paid-ads feature. A "same video, two versions" test in our product would therefore be a custom design (staggered or cross-account publishing and comparing metrics), with Trial Reels as a possible low-risk testing lane on Instagram.

### Cited Findings
- YouTube Test & Compare (Help Center): "You are not able to A/B test Shorts, Scheduled Lives, and Premiere videos at this time." Supports titles and/or thumbnails (up to 3 each); desktop YouTube Studio only; results based on watch time share (not CTR); tests should finish within two weeks; outcomes Winner / Performed Same / Inconclusive. The page describes no API. — [YouTube Help: Test & compare thumbnails](https://support.google.com/youtube/answer/13861714)
- Third-party tool Thumbnail Test claims it can rotate Shorts thumbnails/titles on a schedule (vendor claim, not verified; note Ayrshare says Shorts do not support custom thumbnails). — [thumbnailtest.com](https://thumbnailtest.com/guides/ab-test-youtube-shorts/); [Ayrshare YouTube](https://www.ayrshare.com/docs/apis/post/social-networks/youtube.md)
- Instagram Trial Reels: shows a Reel to non-followers first; introduced December 2024 and rolled out to professional accounts; creator can then share to followers manually or automatically. — [TechCrunch (2024-12-10)](https://techcrunch.com/2024/12/10/instagram-rolls-out-trial-reels-that-arent-shown-to-a-creators-followers); search summary of coverage.
- Trial Reels eligibility: conflicting. One guide citing the Help Center says professional accounts need 200 followers and personal 1,000 and the account must be public; others say 1,000 followers (early 2026 expansion) or no threshold (older TechCrunch-linked piece). Auto-graduation reportedly judged on views in first 72 hours (secondhand). No official Meta threshold found. — [SuperProfile guide](https://superprofile.bio/guides/instagram-trial-reels); [PostFast](https://postfa.st/blog/instagram-trial-reels); [Storrito](https://storrito.com/resources/how-instagram-trial-reels-work-72-hours/)
- API access: Meta's developer changelog of 2025-12-03 says the Content Publishing API now supports creating Trial Reels for both Facebook Login and Instagram Login integrations. Documentation: add `trial_params` with `graduation_strategy` = `MANUAL` (graduate manually in the app) or `SS_PERFORMANCE` (graduate automatically if it performs well). — [Meta Developers blog (2025-12-03)](https://developers.facebook.com/blog/post/2025/12/03/instragram-api-updates/); [Meta: Instagram Content Publishing](https://developers.facebook.com/docs/instagram-platform/content-publishing/)
- Ayrshare says graduation cannot be done via API; trial post requires a single mp4/mov, no carousels/Stories. — [Ayrshare Instagram](https://www.ayrshare.com/docs/apis/post/social-networks/instagram.md)
- Meta's same December 2025 update adds Reels Skip Rate (share of views skipped in the first 3 seconds) among insights metrics. No source found tying insights to Trial Reels or exposing a non-follower breakdown. — [Meta Developers blog](https://developers.facebook.com/blog/post/2025/12/03/instragram-api-updates/)
- A vendor (via search summary) reports a daily cap of roughly 20 Trial Reels via API; not confirmed by Meta. — search summary of [Zernio SDK docs](https://www.rubydoc.info/gems/late-sdk/0.0.1011/Zernio/InstagramPlatformDataTrialParams) and vendor guides
- TikTok: Split testing exists only in Ads Manager; compares two ad groups or campaigns; test types Targeting, Bidding & Optimization, Creative, Smart+, Multi-Variable; 90% confidence threshold; TikTok advises roughly 2 to 6 weeks (a 2025 post). Nothing found on organic-post testing. — [TikTok Ads Help: About Split Testing](https://ads.tiktok.com/help/article/split-testing?lang=en)
- Facebook organic: no native Reels A/B test found; searches only returned the Reels publishing API (Pages only, 30 API posts/24h). — [Meta: Reels Publishing API](https://developers.facebook.com/docs/video-api/guides/reels-publishing)

### Inferences
- A/B of "two edits of the same video" cannot lean on any platform-native organic split tool. Options: (a) Trial Reels on Instagram (publish each variant as a Trial Reel with `MANUAL` graduation, compare performance, graduate the winner in-app); (b) publish variants to different accounts or different times and normalize; (c) paid split tests (TikTok Ads, Meta ads) for statistically cleaner results, but those cost ad spend.
- Trial Reels via API is the one real "native" hook. Caveat: graduation is manual and trial-specific metrics availability is unverified, so product claims should be careful.
- Statistical validity is weak for small agency accounts regardless of method (small audiences, uncontrolled distribution); this is a product-design inference, not a sourced fact.

### Gaps
- Meta's official Help Center page for Trial Reels (eligibility, metrics, graduation rules): not retrieved.
- Whether Instagram Insights API returns data for Trial Reels (and whether it differs once graduated): not found.
- Any Facebook organic A/B feature (Meta Business Suite): not found; Meta Ads A/B test (paid) not researched.
- TikTok organic experimentation: nothing found; absence of evidence only.
- The ~20/day Trial Reels API cap: unconfirmed.

## 4. Post-publish analytics via platform APIs and aggregators

### Takeaway
Instagram offers the richest and best-documented Reels metrics (views, reach, shares, saves, average watch time, skip rate), with up to 48h lag. YouTube Analytics API covers views, watch time and retention curves, but thumbnail impressions/CTR reportedly are not in the interactive API (unverified). TikTok's public API documentation shows only view/like/comment/share counts; watch time and reach are contested. Ayrshare normalizes post and account analytics for 11 networks, but its docs list no per-platform metric fields and refresh at unspecified intervals.

### Cited Findings
- Instagram media insights (Reels): comments, likes, saved, shares, reposts, total_interactions; reach; views; ig_reels_avg_watch_time; ig_reels_video_view_total_time and reels_skip_rate (marked in development); crossposted_views / facebook_views for Facebook cross-posts. `impressions` deprecated for media created after July 2, 2024. Data can lag up to 48 hours; metrics stored up to 2 years; needs `instagram_manage_insights` (Facebook/Unified Login) or `instagram_business_manage_insights` (Instagram Login). — [Meta: Instagram media insights](https://developers.facebook.com/docs/instagram-platform/reference/instagram-media/insights)
- Instagram "CTR" is not a Reels metric in the list above (no link-click CTR for organic Reels found); retention is only average watch time and skip rate, not a per-second retention curve. — [Meta: Instagram media insights](https://developers.facebook.com/docs/instagram-platform/reference/instagram-media/insights)
- YouTube Analytics API (metrics reference): views, engagedViews ("viewed past the first frame, or the user clicks/taps to play"), estimatedMinutesWatched, averageViewDuration and averageViewPercentage (exclude looping-clip traffic since 2021-12-13), shares, subscribersGained; retention via `audienceWatchRatio` with `elapsedVideoTimeRatio` and `relativeRetentionPerformance` (0 to 1 vs similar-length videos). The page does not mention Shorts and does not define impressions/impressionsClickThroughRate. — [YouTube Analytics API metrics](https://developers.google.com/youtube/analytics/metrics)
- In YouTube Studio, impressions and impressions CTR are shown with a card for Videos, Shorts, Live and Posts; for Shorts impressions derive from engaged views. — [YouTube Help: impressions and watch time](https://support.google.com/youtube/answer/9314486?hl=en)
- Third-party claim (an open-source MCP server README, unverified): thumbnail impressions and CTR are not exposed through the interactive Analytics API (reports.query); only the bulk Reporting API "Reach report". — [Search summary of glama.ai MCP README](https://glama.ai/mcp/servers/adilsonicjunior/youtube-analytics-mcp/tree)

### Inferences
- The requested metric set maps unevenly: views, shares, saves, reach: Instagram yes; YouTube views/shares yes, reach/impressions partial; TikTok views/likes/comments/shares only in the documented public API. Saves exist on Instagram; none documented for YouTube/TikTok in what I read.
- "CTR" is the weakest metric: organic short video generally lacks a link-click CTR; YouTube's thumbnail CTR may be Studio-only, and Shorts is feed-based. Product should define "performance" as views, average watch time, skip rate, shares and saves instead of CTR for Instagram.
- Latency up to 48h on Instagram, plus Ayrshare's `nextUpdate` throttling, means A/B conclusions should wait roughly 2 to 3 days after publishing; this follows from the cited lag numbers.
- If we use Ayrshare, we likely get a normalized "views/likes/shares/impressions" view but should verify which per-platform fields (watch time, retention) it returns before committing; if retention curves matter, direct YouTube/Instagram API calls are needed.
